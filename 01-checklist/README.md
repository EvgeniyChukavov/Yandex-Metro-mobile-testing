# Чек-листы

## Описание
Составлены чек-листы для функционального и регрессионного тестирования мобильного приложения Яндекс Метро.

## Что проверялось

### Функциональное тестирование
- Построение маршрута
- Выбор станции на карте
- История о маршруте
- Информация о маршруте
- Детали маршрута
- Смена ориентации (карточка станции, карточка маршрута)
- Логика работы лонг-тапа по станции метро
- Авиарежим или отсутствие соединения

### Регрессионное тестирование
- Сеть и соединение
- Системные события
- Ресурсы устройства
- Построение маршрута
- Кнопка со стрелочками
- Сброс маршрута
- История
- Окно информации о маршруте
- Детали маршрута
- Жесты (карта)
- Тема
- Лонг-тап
- Геолокация
- Обратная связь
- Обновление
- Разрешение
- Запуск приложения

## Тестовое окружение
- Эмулятор Android Studio
- Android 11
- Pixel 2
- Разрешение 1080×1920
- Версия приложения: 3.6
