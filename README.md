# Тестирование мобильного приложения Яндекс Метро

## О проекте
Проведено тестирование мобильного приложения Яндекс Метро для Android: функциональное тестирование (затронутое рефакторингом) и регрессионное тестирование.

**Яндекс Метро** — это мобильное приложение, которое помогает строить маршруты в метро, находить ближайшие станции, прокладывать оптимальные пути.

## Что тестировалось
- **Функциональное тестирование** — построение маршрута, выбор станции, история, детали маршрута, смена ориентации, лонг-тап, авиарежим
- **Регрессионное тестирование** — сеть и соединение, системные события, ресурсы устройства, построение маршрута, жесты, тема, геолокация, обновление, запуск

## Тестовое окружение
- Эмулятор Android Studio
- Android 11
- Pixel 2
- Разрешение 1080×1920
- Версия приложения: 3.6
