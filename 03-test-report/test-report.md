# Отчёт о тестировании Яндекс Метро

- **Устройство:** Эмулятор Android Studio
- **ОС:** Android 11
- **Модель:** Pixel 2
- **Разрешение:** 1080×1920
- **Версия приложения:** 3.6

## Покрытие требований
Все требования, затронутые изменениями, были покрыты чек-листом.

Также написан регрессионный чек-лист.

## Список багов по приоритетам

### Критичные
- BUG1 — приложение работает при отключённом интернете
- BUG2 — приложение работает при включённом режиме полёта
- BUG9 — после тапа «Обратная связь» переходит на неверный сервис

### Средний приоритет
- BUG3 — тема не меняется автоматически на тёмную после 18:00
- BUG7 — в истории сохраняются только первые три станции
- BUG10 — при нажатии на станцию лонг-тапом экран перемещается
- BUG15 — не обновляется интервал времени после создания маршрута

### Низкий приоритет
- BUG4 — при лонг-тапе по станции не открывается карточка с кнопками «Отсюда» и «Сюда»
- BUG5 — свёрнутая карточка маршрута разворачивается при смене ориентации
- BUG6 — неверно открывается карточка полного режима маршрута при смене ориентации
- BUG8 — при смене ориентации детали маршрута не сохраняются
- BUG11 — карточку станции нельзя перевести в режим сворачивания
- BUG12 — карточку станции нельзя перевести в средний режим
- BUG16 — при нажатии на станцию открывается информация о станции

## Рекомендация о публикации
С учётом того, что блокирующих багов не найдено, а критические дефекты не затрагивают основные пользовательские сценарии, команда тестирования не против публикации новой версии приложения в Google Play.

## Дополнительная информация для менеджера

**На что обратить внимание:**
- Приложение работает без интернета — это критично, требует исправления
- Настроить обратную связь для пользователей (BUG9)
- Остальные ошибки являются незначительными, при достатке свободного времени поправить их тоже

**Затраченное время:**
- Написание тестовой документации: 6 часов
- Тестирование: 6 часов

**Применённые виды тестирования:**
- Функциональное
- Регрессионное
- Тестирование мобильного приложения (сеть, системные события, ресурсы устройства, жесты, обновление)

**Рекомендации:**
- После исправления критических багов провести повторное тестирование затронутых сценариев
- Обратить внимание на работу приложения без интернета и в авиарежиме
- Проверить смену ориентации экрана на всех экранах приложения
